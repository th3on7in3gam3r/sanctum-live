# @plcc/brand

Shared tokens and the official Promised Land Christian Center lockup.

## Logo

The logo is ONLY the circle mark + Fraunces wordmark via `<BrandLockup/>`. Never use newlogo.png or any image with baked-in text as a logo. Content imports must not change the logo.

`assets/plcc-mark.png` is the mark. The words “Promised Land” and “Christian Center · Kampala” are set in the component, not drawn into the image.
